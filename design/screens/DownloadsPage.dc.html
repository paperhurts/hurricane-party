WHAT WINDOWS WILL SAY

The first time you run it, Windows will stop you.

A blue panel titled Windows protected your PC appears. That is SmartScreen, and it says the same thing about every program it has not seen before.

Click More info, then Run anyway. It asks once.

Why: hurricane-party is a one-person project and the exe is not code-signed. A signing certificate costs a few hundred dollars a year and would only make this panel go away. The source is public if you want to check what you are running.

WHAT IT IS, AND ISN'T

Offline first. Nothing on the network at playback, ever.

IT IS
A downloader and a player in one small app.
Your files, in a folder you chose, as ordinary MP3 and MP4.
Built to be used in the dark with the power out. The screen is the only light in the room, so the app is dark only.
IT ISN'T
No accounts. No cloud. No sync. No streaming.
No telemetry, no update pings. When you press play it cannot reach the network even if it wanted to.
Not a product. One engineer's tool for riding out hurricane season, shared as-is.

The zip is {{ sizeLabel }} for a 10 MB app because yt-dlp and ffmpeg ride along inside it. Those two do the downloading and the MP3 conversion; hurricane-party is what you look at.

THE WINDOWS

Three small windows that snap together. Drag one, they all come.

MAIN

Transport, time, seek, volume. The analyser runs on a weather radar ramp: green through yellow to red, peaking magenta.

EQUALIZER

Ten bands, a preamp, presets. Auto binds a preset to the track so it comes back when the track does.

PLAYLIST

Resizes by the corner grip. The lit seam between windows is a bond: drag it to resize both neighbours, double-click to break it.

WINDOWSHADE

Collapse Main to a fourteen-pixel bar that stays on top. Title, transport, time. This is the one you live in while working in another app.

FOR TINKERERS

A control pipe and a viz stream.

The player listens on a named pipe. Anything on the machine can ask what is playing, skip, seek, or read the analyser as a stream of frames, which is enough to drive an LED rig from the bass. The protocol is unstable until v1.0. docs/control-api.md has the handshake and the message table.
